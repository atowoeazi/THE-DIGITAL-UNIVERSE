# The Digital Universe

An interactive, responsive universe built with Next.js, React Three Fiber, Three.js, Framer Motion and GSAP.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

To deploy, import this project into Vercel and use the default Next.js build and output settings. No environment variables are required. The 3D scene is rendered in the browser; if WebGL is unavailable, the world directory remains available as a non-3D alternative.
